# Mirutex IDE — проверка обновления 24.10.2026

Продукт переименован в Mirutex IDE. Обновлены светлая и тёмная темы, состояния кнопок и узлов, переходы панелей и уведомлений. Анимации отключаются при prefers-reduced-motion.

## Исправления

- При drag React Flow получает полный набор изменений позиции, размеров и выделения; Dagre больше не пересобирает граф на каждом движении. Выбор узла мышью не запускает центрирование камеры. Позиции и viewport сохраняются по методу/исходнику в пределах текущей сессии.
- Устранены сдвиг меню Monaco из-за конфликта CSS .main и неверная привязка fixed-подсказок к transform анимированной панели. Подключены suggest/snippet contributions и совместимый ввод Monaco.
- Снимки истории восстанавливают также исходную версию сравнения. Новый файл сбрасывает старое выделение, анализ сбрасывает лимит списка; тестовые входы сохраняются локально. Компиляция из другого раздела открывает вывод.
- Java assist предлагает snippets с tabstops, локальные переменные/параметры, собственные методы и типовые методы библиотек. Не предлагает код внутри комментариев/строк; учитывает существующие скобки. Это эвристические локальные подсказки, не полная семантика Java/IntelliJ. Неизвестные типы и зависимости требуют javac.

Всего 66 разных автоматических тестов; 16 интеграционных дополнительно повторены в Compose. Логи лежат в .tools/ide-*.log. Lint завершился без ошибок, с предупреждениями React hooks; Vite предупреждает о размере Monaco bundle.

В браузере проверены: drag без изменения viewport, сохранение позиции при смене темы/метода, ввод sou и принятие sout по Tab, выбор println без дублирования скобок, компиляция результата, анализ, проверенный рефакторинг Main.total → MainComponent.java, применение, сравнение на входах 5/0/3 (три PASS), экспорт ZIP (Main.java и MainComponent.java), восстановление снимка. Производственная сборка отдельно проверена: меню содержит print/printf/println, принятие по Tab; ошибок консоли нет.

Прежние границы сохраняются: атомарный CFG try/catch/finally, ограниченное выделение самостоятельных static-методов, отсутствие полного Java language server. Конечный набор тестов не доказывает эквивалентность всех программ и отсутствие любых багов.
