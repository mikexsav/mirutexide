# Mirutex IDE Studio — обновление 25.10.2026

## Интерфейс

- Оригинальный логотип команды, экран входа user без пароля, светлая/тёмная темы.
- Палитра команд: поиск действий, методов и кода узлов. Ctrl/⌘ Shift P, стрелки, Enter, Escape.
- Карта методов: фильтр по имени/сигнатуре, строка и число узлов, переход к коду и графу.
- Линза изменений: редактируемый интерфейс Monaco DiffEditor в режиме просмотра исходной/текущей версии, создание снимка и переход в историю. Модели diff сохраняются в двух стабильных URI, чтобы корректно закрывать редактор без ошибки disposal.
- Режим фокуса скрывает навигацию и заголовки, освобождая место для редактора и графа.
- Обзор проекта содержит реальные количества файлов, методов, узлов и снимков. Клик по файлу компонента открывает настоящий исходник с подсветкой и экспортом проекта.
- Кнопки этапов сценария, бренд, переключатель проекта, сворачивание меню, профиль, помощь и горячие клавиши имеют действия. Разделитель панелей работает также стрелками клавиатуры. Escape закрывает полноэкранный граф.
- Анимации входа, окон и состояний соблюдают prefers-reduced-motion. Native dialog управляет фокусом и Escape. Анимации не трансформируют canvas графа и Monaco-контейнеры.
- Исправлен размер Monaco: шапка/подвал панели больше не уходят за край при навигации к строке. Устранён выход новых кнопок за экран на ширине 390 px. Исправлены ширины свёрнутого меню/режима фокуса и закрытие уведомления о parse error.

## Доступ на сервере

Вход user — публичный демо-режим, а не индивидуальный аккаунт с серверным хранилищем. Код и снимки остаются в браузере. Отсутствие пароля не выдаёт доступ к исполнению кода.

Host Nginx публикует HTTPS. Явный allowlist допускает POST parse/generate/analysis/upload/download с ограничением частоты. Compile, execute, refactor, compare, graph/edit и /admin/ требуют прежнего HTTP Basic. Проверка находится на сервере, не только в кнопках React. Конфигурация: infrastructure/public-nginx.conf.

Обновлён frontend-контейнер, API и engine сохранились. Все три healthy, nginx и таймер продления сертификата active. Предыдущие frontend-исходники и конфигурация Nginx сохранены в /root/mirutex-backups. Для восстановления старых исходников требуется повторная Docker-сборка.
