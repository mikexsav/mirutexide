# Аудит исходных модулей — 24.10.2026

Исходная папка не содержала Git-репозитория. Все исходные модули сохранены и переименованы по назначению.

| Требование | Исходная реализация | Изменение | Проверка |
|---|---|---|---|
| Java ↔ граф | Только regex-парсер UI, потеря структуры | AST-ядро JavaParser, CFG и проверяемые операции | JUnit + API |
| Анализ | Spring Java: восемь анализаторов, отдельный UI | Сохранены анализаторы, общий API и узлы | JUnit + API |
| Рефакторинг | CLI regex, эвристическая группировка, компиляция | Сохранён CLI; AST-фасад с ограничениями зависимостей | Компиляция + сравнение |
| API | FastAPI с четырьмя заглушками 501 | Java engine adapter, quality gate, download | pytest + integration |
| Запуск Java | Docker, один файл; вывод буферизуется без лимита | Многофайловый запуск, ограниченный вывод, отдельная компиляция | Docker negative cases |
| Frontend | React Flow локально; textarea, фиктивная диагностика | Monaco + серверный граф, диагностика, preview и тесты | build + browser |
| QA | Один JUnit и mock-тесты API | Core, refactoring, API и реальное сквозное сравнение | test scripts |
| 1000 строк | Не проверено | Отдельный демонстрационный монолит | integration benchmark |

Maven выбран вместо миграции на Gradle: оба существующих Java-модуля уже используют Maven. Python backend сохранён для повторного использования изолированного runner.
