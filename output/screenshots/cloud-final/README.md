# Mirutex IDE 2.0 — снимки проверки

1. [Вход и регистрация](01-server-login.png) — Аккаунт с личными проектами или отдельное демо user без пароля.
2. [Личные пространства](02-personal-workspaces.png) — Серверные проекты, версии, файлы, снимки, поиск, копии и архив.
3. [Редактор в облачном пространстве](03-cloud-editor.png) — Текущий код и дополнительные Java-файлы сохраняются на сервере.
4. [Защита двух вкладок](04-conflict-protection.png) — Новая серверная версия не перезаписывается. Локальную версию можно сохранить копией.
5. [Настоящее сравнение после рефакторинга](05-server-behavior-pass.png) — Три сценария PASS для исходной и многофайловой изменённой версии.
6. [Снимок только для просмотра](06-readonly-server-snapshot.png) — Отдельная страница текущего кода и графа, без приватной истории и тестовых входов.

Снято с работающей версии. Проекты и аккаунт на снимках созданы для QA.
